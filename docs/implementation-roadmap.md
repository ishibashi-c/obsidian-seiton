# Release scope

Seiton 0.1.0 provides capture, search, Library, inbox organization, archive handling, and optional Bookshelf, memo, rich-card, and editor-toolbar modules. The [specification](../spec.md) defines product behavior. The [UI Lab map](ui-mock-map.md) describes development fixtures.

This public repository contains a fresh source snapshot and synthetic examples. Private development history and local review artifacts are not distributed. Record future product changes with their compatibility requirements and verification evidence.

See the [release checklist](release-checklist.md) for validation and publication.
